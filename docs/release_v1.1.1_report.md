## Причина выпуска

Ручное тестирование v1.1.0 (T-063) выявило три критичных дефекта и ряд minor-расхождений, часть которых согласована владельцем продукта как изменение требований.

## Что вошло в релиз

### Критичные дефекты (исправлены)
1. **`/transfers` и `/transfers/[id]` недоступны:** HTTP 500 + React error #482. Синхронный `transferStatusLabel` экспортировался из файла с `'use server'`, становился Server Reference и вызывался во время рендера — Next.js запрещает это («Server Functions cannot be called during initial render»). Хелперы вынесены в `transfers/labels.ts`, запросы — в `transfers/queries.ts`, из auth-утилит удалена директива `'use server'`.
2. **Белый экран после входа у КСГП/УСГП/С1С:** `/dashboard` редиректил все роли на `/production-orders`, требующий `production_order:read`. Добавлен ролевой лендинг `getLandingPath()` и ролевое меню.
3. **Сообщение об ошибке отправки Перемещения не отображалось** при превышении остатка («ничего не происходит»): диалог закрывался до установки ошибки. Теперь диалог остаётся открытым, ошибка дублируется баннером на странице.

### Изменения по решению владельца продукта
4. **Права НП на НСИ:** ведение справочников (смены, номенклатура, сотрудники, РЦ, причины) через `nsi:manage`; склады остаются только за АДМ (`nsi:manage_warehouses`, Р-19). Спеки 00 §4.2 и M02 обновлены.
5. **НП получил `transfer:reconcile`** (участие в согласовании расхождений, M08 §3).
6. **Корректировка отправленного Перемещения** (M07 §4.2): правка доступна в DRAFT и SUBMITTED с корректировкой остатков склада-источника — дополнительное списание `ISSUE` при увеличении, возврат `RETURN` при уменьшении, с проверкой BR-1 и записью в аудит.

### Улучшения
7. В форме Перемещения показывается доступный остаток продукта на складе-источнике; при превышении поле подсвечивается красным и сохранение блокируется (BR-1 на клиенте).
8. Добавлен пункт меню «Перемещения» (по правам ролей); скрыт пункт «Отчёты», ведущий на несуществующий маршрут.
9. Кнопки создания/правки/деактивации в НСИ скрываются у ролей без соответствующих прав.

- Многораундовый воркфлоу согласования расхождений отложен на постпродакшен (`docs/postprod_backlog.md`, PP-01).
