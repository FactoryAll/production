## Проблемы и действия

1. **Job «End-to-end tests (Playwright)» был красным на `main` с 05.10.2026** — сценарий ждал селект
   «Категория факта», исчезнувший из диалога внесения итога ещё в `de3e6e5`. Исправлено (T-074),
   job запускается и на pull request, поэтому поломка больше не накапливается незаметно.
2. **Сценарий real-time на дашборде был красным в CI** — он создавал ПЗ для смены №1 независимо от
   времени суток, тогда как дашборд показывает ПЗ текущей смены (Р-05, BR-5). Исправлено: смена
   выбирается по тем же правилам, что в приложении.
3. **Локальная БД.** В этой фазе развёрнут собственный кластер PostgreSQL 16, поэтому миграция и
   идемпотентность сида проверены на чистой базе локально, а не только на VPS. На VPS проверки
   повторяются при деплое (`scripts/postdeploy-check.sh`, шаги 0.2–0.3 плана тестирования).
4. **Тег `v2.0.0`.** Сначала он был поставлен на коммит самопроверки `34070ce` (ПРОЦ-02 §2.2), но ручное
   тестирование выявило дефекты, и исправления вошли в ту же непринятую версию — поэтому тег **переставлен
   на коммит с приёмкой**, как это делалось для `v1.2.0` и `v1.3.0`.
