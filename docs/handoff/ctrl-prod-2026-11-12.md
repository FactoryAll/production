## 1. Что это за проект

ProdTrack — система учёта производства: производственные задания (ПЗ), исполнение смен на рабочих
центрах, складские остатки и перемещения, отчётность, уведомления. Монорепозиторий pnpm + turbo,
Next.js 14 (App Router), PostgreSQL 15 + Prisma, ~1450 тестов.

Первоисточники: `readme.md`, `tech_stack.md`, `specs/` (модули M01…M13), `tasks.md` (бэклог).

Правила целиком — `docs/branching_model.md`, **15 правил**. Ключевые:

- миграции создаются только в `main`;
- **в прод ничего не идёт, пока сценарии не проверены на дев-стенде** (правило 14);
- одна сборка — одна проверка (правило 12);
- с рабочей линией общаемся сами, владельцу — одно задание за раз (правило 13);
- **чужой сайт в nginx не трогать** (правило 15 — цена: MES лежал 2 часа);
- работа не считается сделанной, пока не собрана на проде.

## 4. Как выкатывать (проверенный порядок)

Образ **собирается в GitHub Actions** по тегу и публикуется в GHCR — локальный Docker не нужен:

1. `git tag -a vX.Y.Z` → `git push origin main --tags` — Actions соберёт `ghcr.io/factoryall/production:vX.Y.Z` (≈5 мин);
2. на сервере: `docker pull ghcr.io/factoryall/production:vX.Y.Z && docker tag … prodtrack-web:vX.Y.Z`;
3. `cd /opt/prodtrack && git fetch && git checkout main && git pull && bash scripts/deploy.sh vX.Y.Z --no-build`;
4. `bash scripts/postdeploy-check.sh` — 10 разделов.

`deploy.sh` сам: синхронизирует `VERSION` в `.env`, накатывает миграции, гоняет сид дважды,
проверяет смоук, **сверяет образ работающего контейнера** и падает, если версия не та.

Полностью: `docs/deploy_timeweb.md`. Восстановление с нуля: `docs/disaster_recovery.md`.

## 8. Уроки, которые дорого дались (не повторять)

1. **Проверять факт перед действием.** Отключил nginx-сайт, судя по имени файла, — уронил MES на 2 часа.
2. **Убирать за собой.** Три релиза оставили три образа по 1.7 ГБ — диск дошёл до 92%, до остановки postgres было 100 МБ.
3. **Не раздувать масштаб.** На вопрос «как админу сменить пароль» сделал переделку шапки; владелец просил форму в «Пользователях».
4. **Не называть числа без команды.** Пароль в ответе назвал до проверки состояния базы.
5. **Правило должно жить в одном месте** (`ОПЭ-70/71`, `ОПЭ-73/75`) и **экран показывает то, что в данных**, а не то, что удобно.
