### Проверка событий и записей в БД

- Центр уведомлений (M09) — **Фаза 4**, в UI версии v1.1.0 отсутствует, поэтому события EV проверяются SQL-запросом к таблице `notifications` (запрос выдан тестировщику).
- Выгрузки из БД по `notifications` и `discrepancies` на момент составления отчёта не предоставлены — **остаётся подтвердить** на v1.1.1.
- Косвенное подтверждение событий: изменения статусов и остатков соответствуют ожидаемым переходам (EV-04/EV-05/EV-06/EV-07/EV-10 генерируются в тех же транзакциях, что и переходы).
