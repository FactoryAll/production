# План ручного тестирования ProdTrack v1.0.0

- Дата: 2026-08-24
- URL: https://prodtracker.factoryall.ru
- Версия в футере: v1.0.0
- Тестировщик: <пользователь>

## Подготовка тестовых данных (выполнить перед началом)

### Пользователи (войти как admin/admin123 → /users)
Создать 2 пользователя-Оператора:
- **opr1**: роль OPR, сотрудник с табельным номером T001, РЦ 01.Реактор
- **opr2**: роль OPR, сотрудник с табельным номером T002, РЦ 03.Тубировка крем

> При создании mustChangePassword = true (система автоматически).
> Пароль по умолчанию для новых пользователей — совпадает с логином.

### Смена
Убедиться, что в справочнике смен (/nsi/shifts) есть активная смена, соответствующая текущему времени (1-я смена 08:00–20:00 или 2-я смена 20:00–08:00).
