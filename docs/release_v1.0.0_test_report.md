## Найденные дефекты

| Шаг | Критичность | Описание | Действие |
|-----|-------------|----------|----------|
| 3.2, 7.2 | critical | Unique constraint на `lineId` блокировал ввод ГП+ПФ и ввод за Оператора (нельзя было создать несколько фактов на одну строку) | Исправлено хотфиксом: миграция `allow_multiple_facts_per_line_category` заменила одиночный уникальный индекс на составной (`lineId`, `factCategory`), код ввода факта переведён на `upsert` |
| 4.1 | critical | ПЗ не закрывалось автоматически при переходе всех строк в REPORTED | Исправлено хотфиксом: `checkAndCloseProductionOrder` вызывается после каждого отчёта строки; логика перехода в COMPLETED и генерации EV-03/EV-07 проверена |
| 7.2 | critical | Ввод за Оператора не создавал `ProductionFact` (выпуск = 0, остатки не обновлялись, отчёт смены пустой) | Исправлено хотфиксом: в форму и server action `substituteOperator` добавлены поля выпуска/брака/остановок/потребления; факт, `FactConsumption`, движения остатков и `updateShiftSummary` создаются в одной транзакции |
| 8.2 | minor | Уведомление EV-09 не создавалось при отмене ПЗ | Исправлено: расширен список получателей — операторы строк, все S1C и отменивший ПЗ пользователь; payload дополнен `cancelledByUserId` |
| 5.1 | minor | Диаграммы отчёта смены: красный/чёрный цвет, обрезанные подписи на pie chart, некорректная группировка структуры выпуска (кг+шт в одном pie) | Исправлено: брендовая палитра (`deep-industry-blue`, `signal-amber`, `steel-graphite`, `machine-gray`), `labelLine`, группировка структуры выпуска по категориям (MASS/GP/PF) с долями внутри каждой группы |
| UI | minor | Плохая контрастность текста в кнопках, тесные отступы, большие радиусы скругления; при деплое Tailwind не генерировал классы из packages/ui | Исправлено: обновлены токены кнопок (`--radius-sm: 6px`, `px-5/px-7 py-3`, читаемые цвета), в `apps/web/tailwind.config.ts` добавлен `packages/ui/src` в `content` |
| 1.3 | critical | Ложное срабатывание unique constraint при создании смены на дату, на которую ещё нет смены | Исправлено: `parseDate` в `shifts/actions.ts` строит дату через `Date.UTC(year, month - 1, day, 12, 0, 0)`, чтобы избежать timezone drift в контейнере с TZ=Europe/Moscow |
| 1.1 | critical | При деплое на VPS сборка падает с `TS2305 Module '@prisma/client' has no exported member 'Prisma'` | Исправлено: в `packages/db/package.json` скрипты `build` и `typecheck` теперь запускают `prisma generate && tsc`, в `turbo.json` добавлена зависимость `^db:generate` для `typecheck` |
