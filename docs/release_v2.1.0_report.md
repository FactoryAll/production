## Проблемы и действия

1. **Один коммит был отправлен с красным typecheck** (в тестовой фикстуре не хватало полей `Product`): `vitest` типы не проверяет, а `tsc` поймал. CI по нему упал, следующим коммитом исправлено; с этого момента код возврата пайплайна проверяется до коммита.
2. **Смены в существующих документах.** Все ПЗ, заведённые до обновления, ссылались на шаблонные смены с датой-заглушкой. Без бэкфилла они выпали бы из показателя «производится» и потеряли дату смены, поэтому скрипт входит в план ручного тестирования отдельным шагом.
