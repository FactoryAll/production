# Руководства по прохождению фаз

Директория для документов, описывающих **как организована работа над фазой проекта**: порядок шагов,
роли, форматы взаимодействия, критерии приёмки. Документы не содержат специфики конкретных модулей — только процесс.

## Состав

| Файл | Назначение |
|------|------------|
| `phase_playbook.md` | Универсальный порядок прохождения фазы: старт, самостоятельная проработка спеки, вопросы владельцу, реализация, ручное тестирование, критерии приёмки шага и фазы, завершение и релиз |

## Как пользоваться

1. Перед началом новой фазы — прочитать `phase_playbook.md`.
2. Если для конкретной фазы нужен отдельный уточняющий документ (особенности этапа, состав работ, ограничения среды), он кладётся сюда же рядом с плейбуком.
3. Плейбук — надстройка над `process.md` (ПРОЦ-01…ПРОЦ-05): там нормативные правила, здесь — порядок их применения в диалоге с владельцем продукта.

> Названия документов для отдельных фаз, их обязательный состав и порядок нумерации — **[требуется уточнение]**: в исходном чате зафиксирован только один универсальный документ, договорённости о серии файлов по фазам не было.
