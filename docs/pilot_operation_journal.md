# Журнал опытной эксплуатации (этап 5)

- Начало ОПЭ: 2026-10-12
- Развёрнутая версия: `v2.1.0` — https://prodtracker.factoryall.ru
- Модель этапа: `docs/phase_guides/05_final_testing.md`
- Формат взаимодействия: одно задание на сообщение, подтверждения — текстом

## Как ведётся

- **Одна находка — одна строка.** Строки не удаляются: меняется только статус.
- Нумерация сплошная (`ОПЭ-1`, `ОПЭ-2`, …); на номера ссылаются коммиты и отчёт этапа.
- Статусы: `новая` → `в работе` → `исправлено` → `перепроверено`; либо `отложено` / `отклонено` с причиной.
- **Критичные** дефекты (блокируют работу или искажают данные) исправляются немедленно, вне очереди;
  **некритичные** — сразу после обнаружения.
- Находка закрывается только после перепроверки на развёрнутой версии тем, кто о ней сообщил.
- Исправление обязано иметь тест, который падает без этого исправления.
