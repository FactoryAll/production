| В списке работников предлагаются все сотрудники; решено добавить признак допуска (вариант «б») | **T-071**, nice — в патч-набор v1.3.0 не входит, выполняется в следующей фазе; вариант «в» (связь сотрудник ↔ РЦ) — **PP-04** |
| У АДМ есть `onec:process` по общему правилу проекта, тогда как матрица 00 §4.2 ставит прочерк | пункт 5 отчёта о самопроверке; решения по матрице не требуется в рамках фазы |
