## Найденные дефекты

| Шаг | Критичность | Описание | Действие |
|-----|-------------|----------|----------|
| 1.3 | критичный (белый экран, 500) | Переход по уведомлению EV-01 под Оператором давал серверную ошибку: карточка ПЗ требовала право `production_order:read`, которого у ОПР нет (у него `production_order:read_own`). Дефект существует с Фазы 2, но проявился в Фазе 4: Оператор — адресат EV-01/EV-08/EV-09, а M09 BR-2 требует перехода в целевой объект | Исправлено: карточка принимает `production_order:read` **или** `production_order:read_own`; ОПР видит только строки своего РЦ, чужое ПЗ → 404 вместо 500; роли без права чтения получают экран «Доступ запрещён». Добавлены 4 regression-теста. Нужна повторная проверка шага 1.3 |
