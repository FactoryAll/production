## Проблемы и действия

1. **[закрыто, вне объёма релиза] `tracker.factoryall.ru` отвечает 502.** Диагностика выполнена 06.10.2026
   (вывод владельца продукта):

   | Признак | Значение | Вывод |
   |---------|----------|-------|
   | Контейнеры сервиса `tracker` в `docker ps -a` | отсутствуют (на хосте только `prodtrack_web`, `prodtrack_postgres`, `mes_frontend_prod`, `mes_backend`, `mes_db`) | сервис на этом хосте не запущен |
   | Upstream из nginx | `http://127.0.0.1:8000/` для `server_name tracker.factoryall.ru` | порт 8000 — не наш: `prodtrack_web` слушает `127.0.0.1:3000` |
   | Ошибка nginx | `connect() failed (111: Connection refused) ... upstream: "http://127.0.0.1:8000/"` | никто не слушает порт 8000 |
   | Первые ошибки по tracker в логе | 09:52 и 11:00 — **до** деплоя v1.3.0 (11:17) | 502 существовал до релиза |

   **Вывод:** 502 у `tracker.factoryall.ru` с релизом v1.3.0 не связан — сервис не запущен на хосте,
   nginx проксирует его на порт 8000, где нет слушателя, и ошибки в логе появились раньше деплоя.
   Это внешняя инфраструктура другого продукта, вне объёма Фазы 5; порт ProdTrack (3000) не затронут.
   Рекомендация владельцу: проверить, должен ли сервис `tracker` работать на этом хосте — запуск
   выполняется отдельно и к релизу ProdTrack не относится.

   Побочно в логе видны внешние сканирующие запросы (`GET /.env` на tracker) — к ProdTrack не относятся.
