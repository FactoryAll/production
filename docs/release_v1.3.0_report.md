## Проблемы и действия

1. **`tracker.factoryall.ru` отвечает 502.** Наш деплой затрагивает только compose-проект `prodtrack`
   (`docker compose down/up` в `/opt/prodtrack`), поэтому причина предварительно не связана с релизом,
   но это **не подтверждено** проверкой. Наблюдение из одного места не превращаем в вывод о причине:
   диагностика состояния соседнего сервиса вынесена отдельным заданием, результат фиксируется ниже.
