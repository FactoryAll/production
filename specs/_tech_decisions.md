# Spec

## 1. Принятый стек

| Слой | Решение | Обоснование |
|------|---------|-------------|
| Фронт/бэк | Next.js (App Router) + TypeScript | Единая кодовая база, типизация, SSR/API в одном проекте |
| БД | PostgreSQL + Prisma ORM | Надёжная реляционная БД, типобезопасный доступ, миграции |
| Real-time | SSE (Server-Sent Events) | Простой однонаправленный канал для дашборда и уведомлений; не требует WebSocket-инфраструктуры |
| UI | Tailwind CSS + shadcn/ui | Быстрая разработка, консистентный дизайн |
| Диаграммы | Recharts | Декларативные диаграммы для отчётов и дашборда |
| Авторизация | Сессионная, по ролям (M02), без внешних IdP | Соответствует требованию «без внешних IdP» |

## 2. Решения и допущения

1. **SSE вместо WebSocket** — принято: уведомления и дашборд однонаправленные (сервер → клиент), SSE достаточно и проще.
2. **Prisma ORM** — принято: типобезопасность и миграции важнее сырого SQL для MVP.
3. **Сессионная авторизация** — принято: соответствует требованию, без внешних IdP.
