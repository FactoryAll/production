# Spec

## 1. Назначение и границы

**Вклад в North Star.** Перемещение — это состояние «находится в перемещении». Как только НП сохраняет Перемещение, оно становится видимым КСГП (уведомление) и дашборду (M11), показывая онлайн, сколько ГП в пути на склад ГП.

**In scope:**
- Создание Перемещения: выбор ГП из остатков Производственного склада, указание количества.
- Сохранение Перемещения (переход в `SUBMITTED`).
- Корректировка Перемещения до подтверждения КСГП.
- Статусная модель Перемещения (частично; приёмка — в M08).

**Out of scope:**
- Приёмка и фиксация фактического количества (M08).
- Согласование расхождений (M08).
- Данные для 1С (M12).

## 2. Глоссарий

- **Перемещение** — документ о передаче ГП с Производственного склада на склад ГП.
- **Строка Перемещения** — позиция ГП с заявленным количеством.
- **Заявленное количество** — количество, указанное НП при создании.
- **Сохранение Перемещения** — действие НП, переводящее документ в `SUBMITTED` и уведомляющее КСГП и С1С.

## 4. Доменная модель

### 4.1. Сущности

**Перемещение (Transfer)**
- `id`, `статус`, `создал` (НП), `создано_в`, `отправлено_в`.

**Строка Перемещения (TransferLine)**
- `id`, `перемещение_id`, `номенклатура_id` (ГП), `заявленное_количество`, `фактическое_количество` (заполняется в M08).

### 4.2. Статусная модель

`DRAFT → SUBMITTED → RECEIVED | DISCREPANCY → RECONCILED`, а также `CANCELLED` (см. 00_System_Overview §3.2).

Переходы, относящиеся к M07:

| Переход | Событие | Инициатор | Блокировки |
|---------|---------|-----------|------------|
| `DRAFT → SUBMITTED` | Перемещение отправлено (EV-04) | НП | Хотя бы одна строка с количеством > 0, не превышающим остаток ГП на Производственном складе |
| `DRAFT → CANCELLED`, `SUBMITTED → CANCELLED` | Перемещение отменено (EV-10) | НП | До приёмки (Р-12) |

Правило корректировки: корректировка возможна в `DRAFT` и `SUBMITTED` (до подтверждения КСГП).

## 5. Сценарии (use cases)

**UC-M07-1. Создание Перемещения.**
- Когда НП открывает «Перемещения» → нажимает «Создать» → система создаёт Перемещение в `DRAFT`.
- НП выбирает ГП из остатков Производственного склада, указывает количество → добавляет строки → сохраняет черновик.

**UC-M07-2. Сохранение (отправка) Перемещения.**
- Когда НП завершил составление → нажимает «Сохранить/Отправить» → система проверяет остатки (BR-1) → переводит в `SUBMITTED`, генерирует EV-04.
- Альтернатива: количество превышает остаток → система блокирует с сообщением.

**UC-M07-3. Корректировка Перемещения.**
- Когда НП редактирует Перемещение в `DRAFT`/`SUBMITTED` → система сохраняет изменения.
- Исключение: Перемещение в `RECEIVED`/`DISCREPANCY` → система блокирует корректировку состава (BR-2).

**UC-M07-4. Отмена Перемещения (Р-12).**
- Когда НП отменяет Перемещение в `DRAFT`/`SUBMITTED` (до приёмки) → система переводит в `CANCELLED`, генерирует EV-10; при отмене в `SUBMITTED` возвращает остатки на Производственный склад (M05).

## 6. Бизнес-правила

- **BR-1.** Заявленное количество строки не может превышать остаток ГП на Производственном складе. (Этап: Транспортировка ГП.)
- **BR-2.** Корректировка Перемещения запрещена после подтверждения КСГП. (Этап: Транспортировка ГП.)
- **BR-3.** В Перемещение включается только номенклатура категории «ГП». (Этап: Транспортировка ГП.)
- **BR-4.** Создавать и корректировать Перемещение может только НП. (Этап: Транспортировка ГП.)
- **BR-5.** Списание с Производственного склада происходит в момент отправки (`SUBMITTED`) (Р-03). (Этап: Транспортировка ГП.)
- **BR-6.** Отмена Перемещения: `CANCELLED` из `DRAFT`/`SUBMITTED` до приёмки; инициатор НП; при отмене в `SUBMITTED` остатки возвращаются (Р-12). (Этап: Транспортировка ГП.)

## 7. События и уведомления

- **Генерирует:** EV-04 «Перемещение отправлено», EV-10 «Перемещение отменено» (Р-12).
- **Потребляет:** EV-05/EV-06/EV-07 (обновление статуса — в M08).
- **Уведомляет:** EV-04 → КСГП, С1С; EV-10 → КСГП, С1С (in-app, переход в карточку Перемещения).

## 8. Требования к интерфейсу

- Экран «Перемещения» — список с фильтром по статусу.
- Карточка Перемещения — шапка (статус, дата) + таблица строк (номенклатура, заявленное количество).
- Форма строки — выбор ГП из остатков, указание количества.
- Кнопка «Сохранить/Отправить» — активна при валидных строках.
- Режим редактирования недоступен после подтверждения КСГП.

## 9. Хронометраж

Фиксируются переходы `DRAFT → SUBMITTED` (время отправки) и `DRAFT → CANCELLED`, `SUBMITTED → CANCELLED` (время отмены, Р-12) — связь с M10.

## 10. Критерии приёмки

- [ ] НП создаёт Перемещение из остатков ГП Производственного склада.
- [ ] Сохранение блокируется при превышении остатка.
- [ ] Сохранение генерирует EV-04 и уведомляет КСГП и С1С.
- [ ] Корректировка блокируется после подтверждения КСГП.
- [ ] В Перемещение включается только ГП.
- [ ] Отмена Перемещения (Р-12) работает с возвратом остатков и уведомлением.
