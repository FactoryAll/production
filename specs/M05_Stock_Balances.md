# Spec

## 1. Назначение и границы

**Вклад в North Star.** Остатки — это ответ на «сколько произведено и принято на склад». Модуль обеспечивает онлайн-видимость текущих остатков по обоим складам, что напрямую питает North Star и дашборд (M11).

**In scope:**
- Остатки по номенклатуре на Производственном складе (Масса, ПФ, ГП).
- Остатки по номенклатуре на складе ГП (только ГП).
- Приход остатков из итогов смены (M04).
- Потребление Массы/ПФ при вводе факта (Р-10).
- Списание при отправке Перемещения (Р-03) и приход при приёмке (M08).
- Возврат остатков при отмене Перемещения (Р-12).

**Out of scope:**
- Создание Перемещений (M07).
- Приёмка и расхождения (M08).
- Отчётность (M06).

## 2. Глоссарий

- **Остаток** — текущее количество номенклатуры на складе.
- **Производственный склад** — склад хранения Массы, ПФ, ГП.
- **Склад ГП** — склад хранения только ГП.
- **Приход** — увеличение остатка.
- **Списание** — уменьшение остатка при отправке Перемещения (Р-03).
- **Потребление** — уменьшение остатка Массы/ПФ при вводе факта (Р-10).
- **Возврат** — восстановление остатка при отмене Перемещения (Р-12).

## 4. Доменная модель

### 4.1. Сущности

**Остаток (StockBalance)**
- `id`, `склад_id` (→ M01), `номенклатура_id` (→ M01), `количество`.

**Движение остатка (StockMovement)** [ДОПУЩЕНИЕ: журнал движений для аудита и трассировки]
- `id`, `склад_id`, `номенклатура_id`, `тип` (приход | списание | потребление | возврат), `количество`, `источник` (итог смены | перемещение | приёмка | потребление | отмена), `документ_id`, `создано_в`.

### 4.2. Статусы

Остаток — величина, не имеет статусной модели. Движения — неизменяемые записи (append-only).

## 5. Сценарии (use cases)

**UC-M05-1. Приход из итога смены.**
- Когда Оператор вносит факт (EV-03) → система суммирует фактические количества с остатками Производственного склада → остатки обновляются.

**UC-M05-2. Списание при отправке Перемещения (Р-03).**
- Когда НП сохраняет Перемещение (EV-04) → система списывает указанное количество ГП с Производственного склада.

**UC-M05-2a. Потребление (Р-10).**
- Когда Оператор вносит факт с потреблением → система уменьшает остатки Массы/ПФ на Производственном складе онлайн.

**UC-M05-2b. Возврат при отмене (Р-12).**
- Когда НП отменяет Перемещение в `SUBMITTED` (EV-10) → система возвращает (разблокирует) списанное количество ГП на Производственный склад.

**UC-M05-3. Приход при приёмке.**
- Когда КСГП принимает Перемещение (EV-05/EV-06) → система приходует фактическое количество на склад ГП.

**UC-M05-4. Просмотр остатков.**
- Когда пользователь открывает «Остатки» → система показывает остатки по складам с фильтром по категории/номенклатуре.

## 6. Бизнес-правила

- **BR-1.** Склад ГП хранит только номенклатуру категории «ГП». (Этап: Получение на складе ГП.)
- **BR-2.** Производственный склад хранит Массу, ПФ, ГП. (Этап: Итог смены.)
- **BR-3.** Остаток не может быть отрицательным. (Этап: сквозной.)
- **BR-4.** Остатки изменяются только бизнес-операциями, не вручную. (Этап: сквозной.)
- **BR-5.** Каждое изменение остатка фиксируется движением с источником. (Этап: сквозной.)
- **BR-6.** Списание с Производственного склада происходит в момент отправки Перемещения (`SUBMITTED`) (Р-03). (Этап: Транспортировка ГП.)
- **BR-7.** Потребление Массы/ПФ уменьшает остатки Производственного склада онлайн; превышение остатка — предупреждение, не блокировка (Р-10). (Этап: Производство.)
- **BR-8.** При отмене Перемещения в `SUBMITTED` списанное количество возвращается на Производственный склад (Р-12). (Этап: Транспортировка ГП.)

## 7. События и уведомления

- **Потребляет:** EV-03 (приход из итога и потребление), EV-04 (списание при отправке), EV-05/EV-06 (приход при приёмке), EV-10 (возврат при отмене).
- **Генерирует:** не генерирует уведомлений; изменения остатков отражаются на дашборде (M11).

## 8. Требования к интерфейсу

- Экран «Остатки» — две вкладки/таблицы: Производственный склад и Склад ГП.
- Фильтры: категория, номенклатура, склад.
- Отображение текущего количества по каждой позиции.

## 9. Хронометраж

Не ведётся (остатки — величина). Время движений фиксируется полем `создано_в` и доступно в аудите (M13).

## 10. Критерии приёмки

- [ ] Остатки Производственного склада обновляются при итоге смены.
- [ ] Остатки склада ГП обновляются при приёмке.
- [ ] Склад ГП не принимает не-ГП позиции.
- [ ] Отрицательные остатки невозможны.
- [ ] Движения фиксируются с источником.
- [ ] Потребление уменьшает остатки Массы/ПФ (Р-10).
- [ ] Отмена Перемещения возвращает остатки (Р-12).
