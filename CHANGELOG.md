## [1.1.1] - 2026-10-03
### Fixed
- **Критично:** страницы `/transfers` и `/transfers/[id]` отдавали 500 и падали с React error #482 — синхронный хелпер `transferStatusLabel` экспортировался из файла с директивой `'use server'`, из-за чего превращался в Server Reference и вызывался во время рендера («Server Functions cannot be called during initial render»). Хелперы статусов вынесены в `transfers/labels.ts`.
- **Критично:** белый экран «Application error: a server-side exception has occurred» после входа и после обязательной смены пароля у ролей КСГП, УСГП и С1С — `/dashboard` редиректил все роли на `/production-orders`, требующий права `production_order:read`. Добавлен ролевой лендинг `getLandingPath()` (НП/АДМ → ПЗ, ОПР → Исполнение, КСГП/УСГП → Перемещения, С1С → Остатки).
- **Критично:** при превышении остатка отправка Перемещения блокировалась сервером, но сообщение об ошибке не отображалось («ничего не происходит»): диалог закрывался до установки ошибки, а текст рендерился внутри него. Теперь диалог остаётся открытым, ошибка дополнительно выводится баннером на странице (карточка и список Перемещений).
- Запросы данных вынесены из файлов с `'use server'` в `transfers/queries.ts`, из auth-утилит убрана директива `'use server'` — серверные компоненты больше не вызывают Server Functions во время рендера.

### Added
- **Форма Перемещения:** под полем «Плановое количество» показывается доступный остаток выбранного продукта на складе-источнике (вместо «0.00»), при превышении поле подсвечивается красным и сохранение блокируется (BR-1 на клиенте).
- **Пункт меню «Перемещения»** для ролей с правами на перемещения (НП, КСГП, УСГП, АДМ).
- **Права НП:** ведение справочников — смены, номенклатура, сотрудники, РЦ, причины (`nsi:manage`); участие в согласовании расхождений (`transfer:reconcile`, M08 §3). Склады остаются за АДМ (`nsi:manage_warehouses`, Р-19).
- **Корректировка отправленного Перемещения** (M07 §4.2): правка доступна в статусе SUBMITTED с корректировкой остатков — дополнительное списание `ISSUE` при увеличении, возврат `RETURN` при уменьшении, с проверкой BR-1 и записью в аудит.
- Кнопки создания/правки/деактивации в НСИ скрываются у ролей без соответствующих прав.

### Changed
- Пункт меню «Отчёты» скрыт: страницы-списка `/shift-reports` нет, отчёт за смену открывается из карточки ПЗ (M06).
- Матрица доступа 00 §4.2 и M02 обновлены: управление НСИ разделено на «справочники» (НП, АДМ) и «склады» (только АДМ).

## [1.1.0] - 2026-10-02
### Added
- **M07 Перемещение:** создание и отправка Перемещений (DRAFT → SUBMITTED), списание остатков ГП на Производственном складе (ISSUE, Р-03), EV-04 → КСГП.
- **M07 Отмена:** отмена Перемещения из DRAFT/SUBMITTED (CANCELLED), возврат остатков через RETURN (Р-12), EV-10 → НП+КСГП.
- **M08 Приёмка:** приёмка КСГП с фиксацией фактического количества, переход в RECEIVED (без расхождений) или DISCREPANCY (с расхождениями), приход на Склад ГП (RECEIPT по факту), EV-05/EV-06.
- **M08 Согласование:** согласование расхождений (DISCREPANCY → RECONCILED), корректирующие движения (RECEIPT/ISSUE) на Складе ГП, EV-07 → КСГП.
- **M08 Блокировки:** приёмка отменённого Перемещения невозможна (Р-12), статусная карта блокировок для всех не-SUBMITTED статусов.
- Баланс-сервис расширен: `buildTransferReceiptMovements` для прихода на Склад ГП, компенсирующие движения при согласовании расхождений.
- UI: список/форма/карточка Перемещений, форма приёмки с подсветкой расхождений, форма согласования с корректирующими движениями.

### Fixed
- Все хотфиксы из v1.0.1 включены.

## [1.0.1] - 2026-08-25

### Fixed
- Исправлен составной unique key `production_facts_lineId_factCategory_key`, чтобы разрешить одновременный ввод ГП и ПФ на одну строку ПЗ (замена `lineId` unique index).
- Исправлено автоматическое закрытие ПЗ при переходе всех строк в статус REPORTED.
- Исправлен ввод за Оператора: теперь при подмене создаётся `ProductionFact` с фактическим выпуском, браком, остановками и потреблением; обновляются остатки и отчёт смены.
- Исправлено ложное срабатывание unique constraint при создании смены из-за timezone drift в контейнере с `TZ=Europe/Moscow`.
- Исправлена сборка Docker-образа: `prisma generate` теперь выполняется перед `tsc` в пакете `@prodtrack/db`.
- Уведомление `EV-09` при отмене ПЗ теперь отправляется операторам строк, S1C и отменившему пользователю.
- Исправлены цвета диаграмм отчёта смены (убран красный/чёрный), добавлены выноски подписей на pie chart, структура выпуска сгруппирована по категориям (MASS/GP/PF).
- Исправлены стили кнопок: контрастный текст, увеличенные отступы, радиус скругления 6px; Tailwind теперь сканирует файлы `packages/ui`.

## [1.0.0] - 2026-08-24
### Added
- Полный цикл планирования и производства (M03–M06).
- Создание, подтверждение, корректировка и отмена Производственных заданий (ПЗ).
- Исполнение смены Оператором: подтверждение получения, ввод факта (выпуск, брак, остановки), учёт потребления с предупреждениями при превышении остатка.
- Движения остатков и онлайн-балансы (приход, потребление, корректирующие дельты).
- Формирование итога смены и визуальный отчёт с диаграммами (план/факт, структура выпуска, брак Парето, остановки в формате "чч:мм").
- Сквозной аудит действий и хронометраж переходов.
- Исправление критических блокеров: Middleware без Prisma в Edge Runtime, ролевой редирект /dashboard, фильтрация данных *_own в отчётах.
