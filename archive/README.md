# Архив: репозиторий, из которого проект переехал

**Старый репозиторий:** `https://github.com/FactoryAll/production` — **архивирован**
20.11.2026, доступен только для чтения, история и теги сохранены.

**Куда переехали:** `https://github.com/factoryall-mes-ws/prod-tracker` — здесь ведётся работа.

## Почему папка называется «Архив», а не «старый репозиторий»

GitHub не позволяет «переместить» репозиторий внутрь папки другого репозитория: это разные
сущности. Поэтому сделано две вещи:

1. старый репозиторий переведён в состояние «archived» — в него нельзя пушить, но всё видно;
2. здесь лежит этот указатель, чтобы человек, нашедший проект в старом месте, не искал,
   куда он делся.

## Что это значит для работы

- Весь код, вся история (34 ветки, 34 тега, включая `v2.13.0`) перенесены в новый репозиторий;
- `origin` в рабочих деревьях и на сервере `/opt/prodtrack` переключён на новый адрес;
- образ прода публикуется под новым именем: `ghcr.io/factoryall-mes-ws/prod-tracker`;
- если понадобится сверить со старым состоянием — старый репозиторий доступен, но только на чтение.
